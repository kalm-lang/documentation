# Learn Kalm

Start with the greeting, then work toward a concurrent task-report application.
Use JDK 25+ and build the repository with `mvn install` before following the path.

1. [Run your first greeting](tutorial/01-hello.md).
2. [Make absence explicit](tutorial/02-values.md).
3. [Model values with records and choices](tutorial/03-models.md).
4. [Compose contracts and call Java](tutorial/04-interop.md).
5. [Run tasks, close resources, and tests](tutorial/05-tasks.md).
6. [Explore the complete report](tutorial/06-report.md).

Begin with [getting started](../../docs/quick-start.md), then open the
[hello project](../../examples/hello/README.md). All examples run locally.
