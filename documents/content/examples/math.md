Use numeric prelude overloads for everyday calculations.

```kalm Example.kalm
pub fun main() -> Unit:
    sayLine(abs(-4))
    sayLine(min(2, 5))
    sayLine(max(2, 5))
    sayLine(sqrt(9.0))
    sayLine(pow(2.0, 3.0))
    sayLine(round(2.7))
```
